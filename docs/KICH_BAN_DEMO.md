# Kịch bản video demo (3–5 phút)

1. Giới thiệu ứng dụng và công nghệ Flutter/Firebase.
2. Đăng nhập bằng tài khoản admin Firebase đã tạo (không để lộ mật khẩu).
3. Thêm hồ sơ mẫu, nhập email, mật khẩu demo, họ tên và chọn ảnh.
4. Tìm hồ sơ theo tên/email.
5. Sửa họ tên hoặc ảnh, lưu và xác nhận dữ liệu cập nhật.
6. Xóa hồ sơ demo và xác nhận hộp thoại.
7. Mở Firebase Console, cho xem Firestore document đủ bốn trường và ảnh trong Storage.
8. Chuyển sang emulator/điện thoại; chọn ảnh và xem hồ sơ ở màn hình hẹp.
9. Kết thúc, đưa link GitHub lên màn hình và tải video đến nơi giảng viên truy cập được.

Quay màn hình kèm thuyết minh. Dùng dữ liệu giả lập; tránh lộ thông tin tài khoản thật.
